> Basic formulas and references|SUM adds values and AVERAGE calculates their arithmetic mean. Relative references move when copied. Absolute references such as $F$1 stay anchored.|IF returns one of two values. COUNTIF counts cells matching a condition.|For 8, 10, 6, 9, total is 33 and average is 8.25. : =SUM(B2:B5)
: =AVERAGE(B2:B5)
: =IF(B2>=$F$1,"On track","Follow up")
: =COUNTIF(B2:B5,">=8")
> Lookup and text cleaning|VLOOKUP searches the first column in the table range. Use FALSE for an exact key match. An unknown code should be flagged.

: =LEN(TRIM(C2))
: =CONCATENATE(TRIM(C2)," - ",A2)
